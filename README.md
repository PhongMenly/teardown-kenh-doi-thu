# teardown-kenh-doi-thu

Skill Claude Code để mổ xẻ (teardown) một kênh đối thủ hoặc kênh mẫu trên Instagram, TikTok, YouTube, Facebook rồi dựng báo cáo HTML 13 mục: ảnh khoanh đỏ, bảng số liệu, mổ video từng giây, prompt viết ngược.

- `SKILL.md`: quy trình 8 bước và cách dựng báo cáo.
- `references/`: chi tiết từng bước, cấu trúc báo cáo, kỹ thuật cắt khung video, bài học.
- `scripts/`: giải mã giờ đăng từ mã bài Instagram, phân tích số liệu, gộp báo cáo thành một file (cần Python 3).
- `assets/`: mẫu báo cáo HTML và CSV mẫu (số giả).
- `vi-du/zara/`: **báo cáo mẫu thật** teardown kênh @iamfacelesszara (mở `bao-cao-teardown-zara.html`).
- `nhat-ky-teardown.md`: sổ các lần teardown đã làm.

Ảnh trong `vi-du/` là ảnh chụp nội dung công khai của kênh được phân tích, dùng để minh hoạ phân tích; bản quyền thuộc chủ kênh. Tên người bình luận đã được che.
